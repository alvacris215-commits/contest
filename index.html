4 · Timer phases

The phases run in order after the tickets are drawn. For example: Preparing → Presenting → Questions.

Timer behaviour

Keys while a timer is running: Space pause/resume Enter / → end this phase now ↑ add 10 s ↓ remove 10 s Esc menu

5 · Scoring

After the timers, each person is scored by the judges set in the Structure tab. After the last person's score, the next key press draws the next round. When everyone in the stage has presented, the ranking is shown.

In titles you can use {round} round number, {name} first person drawn, {last} latest person drawn, {team} everyone drawn so far, {n} and {total} ticket number and tickets per round.
